# PatternRecognition

패턴인식 수업의 주차별 실습과 프로젝트 제안서를 모은 폴더입니다.

## 구성

- `2주차실습_곽소영_2025254008.ipynb` : 2주차 실습 노트북
- `3주차실습/` : 선형 회귀(California housing 특징 1개/8개 비교), 로지스틱 회귀, 경사하강법(moons 데이터)
- `4주차실습/` : 신경망 회귀 손실 비교, 다중 분류, 기울기 소실, 과적합(데이터 크기·모델), 클래스 불균형 데모
- `12주차 Project Proposal/` : 「합성 피부종양 이미지 기반 이상탐지 및 분류모델링」 프로젝트 제안(발표 PPTX와 `data`, `notebooks`, `src`, `models`, `results` 작업 폴더 구조)

## 사용

각 `.ipynb`는 Jupyter Lab/Notebook에서 열어 위에서부터 실행합니다. 제안서 폴더의 데이터는 용량 문제로 비어 있을 수 있습니다.
