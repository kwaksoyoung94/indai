# IntelligentCapstone

지능화캡스톤 과목의 실습과 화재 감지 프로젝트를 모은 폴더입니다.

## 구성

- `3주차실습자료/` : 영상·이미지 처리 실습 예제(`ex1.py`~`ex9.py`)와 샘플 이미지/영상
- `fire_smoke_detection/` : 감시카메라 화재·연기 탐지 시스템. 공간·시간 특징(SSIM, MSE, Wavelet)과 Faster R-CNN으로 오탐을 줄이는 논문 구현
- `optical_fire_false_alarm_detection/` : 광학적 간섭에 의한 화재 오탐 감지 시스템 초기 버전
- `industrial_fire_dectection/` : 캡스톤 당시의 산업 현장 화재 감지 코드(TensorFlow 기반). 현재 진행 중인 연구 코드는 저장소 최상위의 [industrial_fire_dectection](../industrial_fire_dectection/README.md)에 있음
- `TASK.md` : 프로젝트 개발 지시 및 연구 정리 문서(목적, 기존 프로젝트 분석)
- 발표양식 PDF : #1 발표평가 자료

각 하위 프로젝트의 사용법은 해당 폴더의 `README.md`를 참고하세요.
