# UCI-SECOM Golden Dataset

**반도체 센서 데이터를 5대 품질 지표로 정제** | 1,567건 → **103건** | 590센서 → **582센서**

---

## 🎯 5대 데이터 품질 지표

| # | 지표 | 조건 | 파라미터 | 결과 |
|---|-----|------|--------|------|
| 1 | **유일성** | (Time, Pass/Fail) 중복 제거 | - | 30건 제거 |
| 2 | **완전성** | 결측치 >70% 센서 제거, 행당 >5개 결측 제거 | THRESHOLD=70%, PER_ROW=5 | 1,442건 제거 |
| 3 | **유효성** | Pass/Fail 범위 검증 [-1,1], 음수값 제거 | VALID_LABELS=[-1,1] | 0건 제거 |
| 4 | **일관성** | 동일 Time의 다른 Pass/Fail 제거 | - | 6건 제거 |
| 5 | **정확성** | IQR 기반 이상치 제거 | IQR_MULT=1.5 | 0건 제거 |
